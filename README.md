## How I Approach Projects

I approach software from both the **business and technical sides**.

### 01 — Understand

Identify the business objective, users, workflows, constraints, and requirements.

### 02 — Structure

Translate requirements into product flows, data models, interfaces, and technical architecture.

### 03 — Build

Develop the product using modern full-stack technologies with an emphasis on maintainability, usability, and type safety.

### 04 — Refine & Deploy

Test the product across devices, handle edge cases, improve performance and security, and deploy the final application.
