## 📌 Selected Projects

### 1. BusinessOS
Full-stack business management platform that centralizes operational workflows, CRM client records, itemized invoicing, appointment bookings, and financial tracking into a unified workspace.

Growing businesses frequently operate on a fragmented stack of disconnected tools—leads in one app, billing in another, bookings on external calendars, and cash flow in spreadsheets. BusinessOS unifies these daily operations into a single command center to eliminate data silos and manual reconciliation.

**Key features:**
- Executive dashboard with real-time cash flow metrics, revenue KPIs, and receivables tracking
- CRM pipeline with deal stages, client records, and interaction history
- Itemized invoice generator with automated tax calculation, payment statuses, and billing logs
- Resource scheduling calendar for client appointments and staff availability
- Role-based access control (Admin, Manager, Staff) with permission boundaries
- Relational database architecture with cascading integrity constraints

**Stack:** Next.js 15 (App Router) · TypeScript · PostgreSQL · Prisma ORM · Tailwind CSS · Recharts

### 2. Gym CRM
Facility operations and member management platform engineered to streamline front-desk check-ins, membership renewal tracking, staff access control, and recurring revenue reporting.

Fitness centers often face front-desk bottlenecks, unmonitored membership expirations, and manual attendance tracking. Gym CRM provides rapid lookup tools, dual-path registration (Admin vs. Member), and automated visual renewal alerts before memberships lapse.

**Key features:**
- Front-desk QR attendance check-in terminal with instant member search and access logs
- Searchable member directory with visual subscription status badges (Active, Expired, Frozen)
- Multi-role RBAC supporting 5 distinct permission levels (Admin, Manager, Trainer, Receptionist, Member)
- Point-of-sale merchandise catalog, inventory tracking, and receipt records
- Operational reporting and facility metrics tracking monthly recurring revenue (MRR)
- Dual-mode persistence ensuring zero-downtime reliability via PostgreSQL and fallback cache

**Stack:** Next.js · TypeScript · Tailwind CSS · PostgreSQL · Prisma ORM · Recharts  
[Live Demo](https://gym-crm-gules.vercel.app/) · [Repository](https://github.com/youssefmanssouri/gym-crm) · [Case Study](https://www.youssefmanssouri.site/projects/gym-crm)

### 3. WealthFlow
Personal finance mobile application built with React Native and Supabase for real-time transaction tracking, budget management, and personal cash flow visibility.

Everyday budgeting applications are often cluttered with unnecessary complexity or lack instant synchronization, making regular expense logging friction-heavy. WealthFlow simplifies personal financial tracking through quick transaction entry, category budget thresholds, and progress-driven savings goals.

**Key features:**
- Income and expense transaction tracking with merchant metadata, category tagging, and search
- Monthly category budgeting with visual progress indicators and spending threshold warnings (80% and 100%)
- Goal-oriented savings trackers with milestone contributions and target dates
- Persistent session hydration via AsyncStorage and database-level Row Level Security (RLS) via Supabase
- Financial summary telemetry displaying net cash flow, savings rates, and SVG category distribution
- Support for 7 global currencies (USD, EUR, GBP, MAD, JPY, CAD, AUD) and structured JSON data export

**Stack:** React Native · Expo SDK 52 · TypeScript · Supabase · PostgreSQL · React Navigation v7 · AsyncStorage

### 4. Lumière Parfums
Custom luxury fragrance e-commerce experience designed for sensory product storytelling, guided olfactive discovery, and seamless purchase flows.

Online fragrance shoppers cannot physically smell products through a screen, making standard e-commerce grid layouts ineffective for product evaluation. Lumière Parfums resolves this by structuring fragrance discovery around olfactory accords and scent pyramid breakdowns.

**Key features:**
- Interactive fragrance catalog with multi-attribute filtering by olfactory notes and fragrance accords
- Detailed product presentations with top, heart, and base scent pyramid breakdowns and bottle format variants
- Persistent slide-out cart drawer maintaining bag state across navigation via LocalStorage
- Simulated demonstration checkout workflow with immediate order confirmation and receipt generation
- Customer account portal with order history tracking and saved preferences
- Administrative store portal for managing inventory levels, product catalog, and pricing

**Stack:** Next.js 15 (App Router) · TypeScript · Tailwind CSS · React 19 · Prisma ORM · PostgreSQL
